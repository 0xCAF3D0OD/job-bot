# Glossaire : Allemand (de-CH, sans ß)

Figé (Kevin, 17.11.2026) : un terme ne change que par une décision de Kevin, puis dans tous les écrans à la fois. Lu par `make i18n-check` (docs/147 §5). Tutoiement : « du ».

Contrôle : `make i18n-check` refuse une traduction dont le texte français contient un mot de « Contrôle FR » (mot entier, sans tenir compte des majuscules) sans contenir l'un des mots de « Contrôle » (n'importe où dans le texte). Vide : terme trop ambigu pour un contrôle automatique, vérifié à la relecture.

Statut : « officiel » = titre ou terme relevé sur arbeit.swiss (SECO) le 17.11.2026 ; « usage administratif, à relire » = terme courant de l'administration, pas encore vérifié sur une source ; « proposition, à relire » = aucune version officielle trouvée.
